**Button** — EmberTribe's bold pill CTA; use for any primary/secondary action.

```jsx
<Button variant="primary" size="lg">Get a growth plan</Button>
<Button variant="outline">See our work</Button>
```

Variants: `primary` (Candy Apple Red), `dark` (rich black), `outline`, `ghost`. Sizes `sm | md | lg`. Props: `disabled`, `fullWidth`, `iconLeft`, `iconRight`, `as` (e.g. `"a"` for link buttons). Labels stay short and confident.
