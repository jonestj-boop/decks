**Logo** — renders an official EmberTribe lockup from `assets/logos/`. Never redraw the mark.

```jsx
<Logo variant="primary" basePath="../../assets" height={40} />
```

`variant`: primary | napkin-horizontal | napkin-stacked | napkin-vertical. Set `basePath` to the relative path from the current page to `assets/`. On dark backgrounds use the primary lockup and keep maximum contrast.
