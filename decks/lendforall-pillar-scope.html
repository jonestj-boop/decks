Two treatments, two price lines

The honest way to quote it: bespoke work priced as bespoke, repeatable work priced as repeatable.
1 · Custom rewrites (2 pages)

child-tax-loans + loans-without-employment-verification

  • Unique topics: each page fully researched and rewritten around its own striking-distance queries
  • Built to Nick's structure: top snippet, loan calculator, accordion main content, accordion FAQs
  • Fewer, better FAQs, written from the real queries in Search Console
2 · Lender template refresh (11 pages)

One improved review template, applied across the shelf

  • All 11 are the same page type with the same gaps, holding brand queries at positions 9 to 24 ("icash reviews", "is loan away legit", "lend direct")
  • One design pass: structure, tightened accordion FAQs from real queries, Review/FAQ schema
  • Then applied per lender with page-specific facts. One pass, the whole shelf moves
One flag before writing: the no-employment-verification page ranks on queries like "1 hour loans no employment verification", which is exactly the query class Google's June spam update repriced (it is why the homepage slipped on instant/no-refusal terms). That rewrite should lean eligibility and compliance, not speed-and-no-checks promises.
