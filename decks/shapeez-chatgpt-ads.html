What Changed

ChatGPT Just Became a Paid Channel

Ads had been quietly live in ChatGPT since February 2026. On July 22, OpenAI opened the self-serve Ads Manager broadly — turning it from a closed pilot into a channel any advertiser can test today.

What's New

  • → Targeting is conversational, not keyword — OpenAI matches advertiser "context hints" to real-time conversation intent via a second-price auction
  • → Two objectives: Reach (CPM, ~$60 default max bid) and Clicks (CPC, $3–$5 recommended starting bid)

What to Know Before Testing

  • → Ads shown only to ChatGPT free-tier users — Plus, Team, and Enterprise stay ad-free
  • → Ads appear as a clearly labeled, tinted sponsored card below the AI's response — they don't alter the answer itself
  • → Platform is genuinely new — no multi-year benchmark history like Google or Meta
  • → $100M in 6 weeks signals real advertiser demand, but also rising competition for placements over time

How It Works

Product Feed Ads — Built for Brands Like Shapeez

The format OpenAI is pushing hardest is product feed ads: connect a catalog, and ChatGPT auto-generates sponsored placements inside relevant conversations. It's the same underlying asset Shapeez already maintains for Google Shopping and Performance Max.

📦

1. Connect the Feed

  • Same product catalog structure used for Google Shopping / PMax
  • Handles up to 1M SKUs — far beyond Shapeez's catalog size
  • Set eligibility filters for which items are served
🎯

2. Context-Matched Serving

  • Advertiser supplies "context hints" — topics, scenarios, product types
  • OpenAI matches those to live conversation intent (e.g. "what to wear under a fitted dress")
  • Served via second-price auction, not keyword bidding
🏷️

3. Labeled Sponsored Card

  • Product name, image, and catalog attributes shown as a clearly marked "Sponsored" card
  • Appears below the AI's response — never inside it
  • CPC or CPM billing, no minimum spend
Why this matters for Shapeez: there's no new creative system to build. The Google Shopping feed Shapeez already runs is the input this format needs — the lift is almost entirely in connecting it and setting a test budget.

Risks & Guardrails

What Could Go Wrong — and How We'd Catch It

Treating this honestly as an early-platform test, not a sure thing.

Real Risks

  • → Reach is capped to free-tier users only — a real but bounded audience ceiling
  • → No multi-year benchmark data exists yet for CPA/ROAS expectations by category
  • → Early advertiser demand ($100M in 6 weeks) could push CPCs up faster than expected
  • → Attribution/measurement tooling is newer than Google's — expect a learning curve on reporting

Guardrails Built Into This Plan

  • → Test budget is capped and isolated — it doesn't touch the existing $3,785.65/mo program
  • → CPC-first (not CPM) keeps spend tied to clicks, not just impressions
  • → Fixed 30–45 day checkpoint before any budget increase
  • → Ads are clearly labeled "Sponsored" and never alter ChatGPT's actual response — no brand-safety exposure inside the answer itself
